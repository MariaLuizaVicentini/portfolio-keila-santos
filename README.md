# 🚀 Portfólio Keila Santos

Projeto desenvolvido inicialmente com auxílio de IA e atualmente em processo de **refatoração, testes e evolução arquitetural**, com o objetivo de transformar a implementação inicial em uma aplicação mais **organizada, escalável, testável e preparada para publicação**.

## 🎯 Objetivo

Aplicar e aprofundar na prática os conceitos teóricos acumulados através de estudos diários e da experiência recente de mercado, fortalecendo a arquitetura e a qualidade do código.

A implementação inicial foi gerada com auxílio do [Lovable](https://lovable.dev/), servindo como ponto de partida para o desenvolvimento.

A partir dessa base, o projeto está sendo evoluído com foco em:

* Refatoração do código existente;
* Melhoria da organização e estrutura do projeto;
* Criação de testes automatizados;
* Redução de acoplamento entre responsabilidades;
* Melhoria da legibilidade e manutenção do código;
* Definição de uma estrutura preparada para crescimento;
* Boas práticas de desenvolvimento;
* Preparação para publicação em produção.

## 🛠️ Tecnologias

* **TypeScript**
* **React**
* **TanStack Start**
* **Tailwind CSS**
* **Vite**

## 📁 Estrutura do projeto

A estrutura inicial do projeto está organizada da seguinte forma:

```text
src/
├── components/
├── routes/
├── ...
```

> A estrutura será evoluída conforme as necessidades do projeto, evitando abstrações e complexidade desnecessárias.

## 🧪 Testes

Uma das etapas deste projeto é a implementação de uma estratégia de testes automatizados.

O objetivo é garantir que as principais funcionalidades possam ser alteradas e refatoradas com maior segurança, reduzindo regressões durante a evolução da aplicação.

Os testes serão incorporados gradualmente conforme as funcionalidades existentes forem revisadas.

## 💻 Desenvolvimento local

### Pré-requisitos

* [Node.js](https://nodejs.org/)
* npm

Recomenda-se utilizar o [nvm](https://github.com/nvm-sh/nvm) para gerenciamento da versão do Node.js.

### Instalação

Clone o repositório:

```bash
git clone <url-do-repositorio>
```

Acesse o projeto:

```bash
cd <nome-do-repositorio>
```

Instale as dependências:

```bash
npm install
```

Inicie o ambiente de desenvolvimento:

```bash
npm run dev
```

Após iniciar a aplicação, acesse a URL exibida no terminal.

## 📦 Scripts

| Comando           | Descrição                                        |
| ----------------- | ------------------------------------------------ |
| `npm run dev`     | Inicia o ambiente de desenvolvimento             |
| `npm run build`   | Gera a versão de produção                        |
| `npm run preview` | Executa localmente a versão gerada para produção |

> Os comandos disponíveis podem variar conforme a configuração atual do projeto.

## 🔄 Processo de evolução

O projeto está sendo desenvolvido de forma incremental.

As principais etapas previstas são:
1. Criar testes para as funcionalidades importantes;
2. Conhecer e documentar a implementação existente;
3. Identificar pontos de acoplamento e código duplicado;
4. Refatorar mantendo o comportamento existente;
5. Melhorar a organização e separação de responsabilidades;
6. Revisar a estrutura pensando em escalabilidade;
7. Documentar as decisões e padrões adotados.
8. Preparar o projeto para publicação;


A prioridade é **evoluir a aplicação gradualmente**, evitando alterações desnecessárias e mantendo o projeto funcional durante o processo.
